# 🛍️ Shopping Website

A responsive shopping website built to practice modern frontend layout, styling, and responsive web design using HTML5 and CSS3.

The project focuses on creating a clean and user-friendly shopping interface with a product-oriented layout and responsive design.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sakibhasan077/Shopping-website.git
```

### 2. Navigate to the project directory

```bash
cd Shopping-website
```

### 3. Run the project

This is a static HTML and CSS project, so no package installation is required.

You can open the `index.html` file directly in your browser.

For a better development experience, you can also use the **Live Server** extension in VS Code.
